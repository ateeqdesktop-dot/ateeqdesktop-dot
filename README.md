# Ateeq Janam Dev

Software engineer building **trustworthy, reproducible, and inspectable systems**.

I focus on the engineering boundary between AI capability and operational trust: evidence, provenance, deterministic evaluation, privacy-aware debugging, and failure-resistant developer tools.

## Flagship projects

[CounterSeal](https://github.com/ateeqdesktop-dot/counterseal) is an offline evidence decision engine for AI-enabled software changes. It composes tests, security scans, evaluations, traces, and attestations into explicit claims, policy findings, approvals, abstentions, and deterministic decision capsules that another engineer can verify independently.

> Make every AI change explainable, reviewable, and independently verifiable.

[MCP Lantern](https://github.com/ateeqdesktop-dot/mcplantern) is a local-first security and contract gate for Model Context Protocol servers. It turns MCP manifests and discovery documents into deterministic, explainable CI artifacts with stable rule IDs, bounded redacted evidence, policy thresholds, report integrity verification, and JSON/Markdown/SARIF/JUnit output.

> Inspect the capability. Explain the risk. Gate the merge.

[FaultPack](https://github.com/ateeqdesktop-dot/faultpack) remains the core failure-evidence interchange: a local-first, privacy-preserving format for reproducible software failures and AI-agent/tool runs, with signed artifacts, replay, reduction, semantic diff, SARIF/JUnit reports, and a reusable GitHub Action.

> Capture once. Share safely. Verify independently. Replay anywhere.
